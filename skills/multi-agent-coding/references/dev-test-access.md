# ELYS dev 测试访问

仅适用于 ELYS，不把账号授权扩展到 EVE、其他项目或 fat/prod。账号配置与凭证不进入 Skill 包、Git、公开网站、简报或测试报告。

## 私有配置

读取当前用户主目录下 `.config/elys-testing/dev-accounts.json`；它位于技能目录之外，目录权限 0700、文件权限 0600。本机已录入三个用户授权的 dev 测试账号；不存在或无法读取时向用户请求配置，不从公开文件或任意历史日志猜凭证。

- `accounts`：允许使用的账号及报告用别名。
- `environment`：必须是 dev；不得删除这些账号。
- `approved_api_origins`：经核实的真实后端 origin 白名单。空列表表示尚未绑定具体地址，不能只凭配置写 dev 就登录；先从当前项目 dev 配置、路由/代理及运行时证据核实，无法确认时阻断。未经核实不自动填入地址。
- `credential_source`：验证码/密码的私有来源；未配置则由用户提供或采用当前已授权的安全凭证源，不猜测、硬编码或打印到日志。

## 操作前检查

1. 从实际运行配置确认客户端 API base、BFF/本地代理最终上游以及后端依赖指向；记录脱敏环境证明。localhost 可能代理 prod，不能仅凭窗口标题、分支名或 localhost 判定 dev。
2. 用已核实的 dev origin 及依赖环境证明匹配目标；无法证明或发现 fat/prod 就 EVIDENCE_BLOCKED，停止登录和写操作。
3. 核对账号属于私有白名单，按任务分配别名，避免并行 worker 共改同一业务 fixture。仅在获准 dev 的任务测试范围内创建/编辑测试数据；禁止删除/注销这些账号。
4. 删除业务数据、批量重置、影响其他用户、支付或向未授权对象发送消息，仍需对应操作的明确授权；账号可用不等于获准任何破坏性操作。
5. 只向实际执行登录的工具提供必需凭证；台账仅记录账号别名、环境证明、fixture 标识与证据路径。截图/trace 中的令牌、验证码和私人信息脱敏。配置不随公开发布同步。

## 本机测试产物

遵循当前机器 AGENTS.md 的 T9 存储规则。Go/Xcode 构建测试经 t9-dev，间接脚本检查缓存/DerivedData/大产物覆盖；T9 缺失、UUID 不符或不可写则停止依赖其的构建，不回退本机缓存。任务单传递该约束，完成时只报告实际核实的缓存和产物位置。
