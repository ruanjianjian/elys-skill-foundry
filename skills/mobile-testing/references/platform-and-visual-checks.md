# 跨层、视觉与生命周期检查

根据功能选择检查项；将平台差异纳入矩阵，不默认 iOS 通过就意味着 Android 通过。

## Flutter 与原生交界

- Flutter：布局约束、滚动、列表复用、状态更新、焦点和键盘、Semantics。golden 比对需固定字体、DPR、主题和文本倍率。
- iOS：SwiftUI/UIKit 导航、sheet/alert、交互式返回与取消、系统安全区、Dynamic Type、VoiceOver、原生分享/相册/权限、生命周期回调。
- Android：系统返回、权限/相册、键盘调整、TalkBack、字体缩放、重建后的状态恢复；与 Flutter 路由结果对照。
- 混合宿主：检查 PlatformView/WebView 的点击命中、手势冲突、遮挡、层级和返回链；Flutter finder 不保证能看见原生树。
- 原生弹窗：分别验证呈现、文本/按钮、取消、确认、重复触发和消失后的焦点/页面状态。debug bridge 能证明 handler 或业务链的结果，真实原生点击需独立交互证据。

## 视觉和动效

- 截图比较同一页面、内容、设备/OS、字体倍率、主题、方向和键盘状态；动态时间/头像/网络图等先识别为噪声，不能大范围遮罩隐藏缺陷。
- 查看布局、遮挡、截断、字号/间距一致性、图片比例、底栏/安全区、触控目标、错误和 loading 提示。无认可基线时交付具体启发式发现，不宣称像素一致。
- 选项目支持的小屏/大屏与大字体；适用时增加横屏、深色和减少动态效果。不是所有改动都需要全设备矩阵。
- 录屏覆盖转场和手势起止/中间过程，检查快速连点、拖动取消、动画中返回和键盘出现/消失。截图不能证明没有掉帧或命中区域正确。
- VoiceOver/TalkBack 的朗读顺序和可操作性需真实辅助功能操作；语义树检查只能作为部分证据。无法执行时写明未覆盖。

## 生命周期和真实平台能力

- 主路径及相关 loading/empty/error/disabled/offline/slow-network/expired-auth 状态。
- 前后台、锁屏/中断后恢复、路由返回和重复进入；进程重启或权限重置只在获准测试设备和数据范围执行。
- 媒体：选择→上传→处理→播放→暂停→中断→恢复，按功能检查进度/错误恢复；从最终 UI 和后端结果验证，mock 播放器不算播放验收。
- 性能：帧耗时/卡顿、启动、内存或长列表测量记录机型、构建模式、工具和采样条件。使用项目预算，无预算则给实测值和判断依据。

只对收集到的证据下结论。触觉、真实推送/第三方 App、硬件媒体和网络体验，依赖真机/服务时保留对应未验证项。
