# Web 视觉与状态检查

按变更范围选择检查项，并把未执行的相关项保留在报告里。

- 流程状态：loading、空、成功、错误、禁用、提交中、超时/重试；刷新、返回、路由直达后的状态；弹窗 Escape/遮罩/关闭/确认差异。
- 视觉：参考设计或旧版本与当前截图使用相同内容、字体、viewport、DPR、zoom、主题；检查遮挡、截断、层级、间距、图像比例、固定底栏和滚动容器。没有认可的基线时只能做启发式检查，不能宣称像素级一致。
- 响应式：按项目目标选桌面和窄屏，检查根页面横向溢出与组件内合法横滑；在关键断点两侧验证重排。200% 浏览器原生缩放与缩小 viewport 分别记录，不能等价宣称。
- 无障碍：键盘主流程、焦点可见、弹窗焦点进入/限制/返回、可访问名称、错误关联和状态通知；axe 扫描覆盖当前实际页面和状态。无障碍树或自动扫描不能替代真实屏幕阅读器验证。
- 交互：重复提交、连续打开/关闭、长文本、键盘导航、失焦、搜索过期响应、错误后重试，关注可恢复性和最终持久化状态。
- 动效：录制开始/中间/结束状态，检查跳动、闪烁、过渡结束后点击区域；静态截图不能证明流畅。像素对比为稳定页面可暂停动画，但另跑正常动画路径。
- 性能：使用相同设备/限速/缓存条件的 trace；实验室一次运行不能作为真实用户 p75 指标。沿用项目阈值，缺失时明确测量值而非武断判定。

技术命令以当前已安装工具 help/schema 和项目测试配置为准。
