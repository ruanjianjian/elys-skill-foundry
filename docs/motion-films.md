# Skill Foundry 悬停短片集

用户目标：在技能卡片里直接看懂用途，按需安装。站点：https://ruanjianjian.github.io/elys-skill-foundry/ 。

9 个技能分别使用手绘叙事、纸片侦探、黏土游乐场、午夜城市、建筑模型、机械修理厂、光学实验、夜航快递、编辑手账。每支 14–16 秒，有自己的镜头、动作和原创合成配乐。页面恢复原始纸白网格、钴蓝、朱红、深墨配色与彩墨液态材质；默认是简洁技能卡，悬停在同一卡片显出短片，没有独立播放器。旧 `?cut=cinematic` 地址进入同一套完整片库。

桌面悬停或键盘聚焦开始预览，离开、离屏、页面隐藏立即暂停并静音，每次仅播放一支。声音默认开启意图，只随当前视频播放；浏览器拦截时静音预览并提示点击开声。关闭声音后，普通点击、再次悬停及重载均保持静音，只有显式开启才恢复。手机点按播放/暂停；减少动态和静态模式只允许手动播放。

图画和剧情是能力宣传示意，不代表技能业务实录或实际部署验收。新 2 项只提供私有源链接，不重新公开技能源码；既有 7 项技能源码及 ZIP 不变。

原创原画使用内置 imagegen，Canvas 代码绘制动作、剪辑及转场，纯 Python 合成配乐，不使用参考片的角色、画面、音轨或第三方音乐采样。完整原画提示词与制作方式见 [制作记录](collection-art.md)。参考研究已实际播放用户给出的三条小红书视频；学习连续角色、材质统一、远中近切镜和具体动作隐喻，没有宣称听证参考音乐。

重建方式见 [README](../README.md)。当前报告仅展示本轮最新核心动线，历史尝试保留，不混为当前结论。

恢复依据：原始 d245f2c 的色板与 Liquid 参数。标题保留原四句、3s 停留与 300ms/100ms 转场、黏连液滴；九卡用独立 React 装饰岛恢复角标，不挂载旧七卡 Grid。桌面意图列 1.24fr/其余 .88fr、880ms，离开视觉回落 160ms；固定片窗高度避免纵向抖动，视频用 contain 保留完整画面。复制成功反馈 380ms，入场 220ms/前三张 40ms 错峰。系统/手动减少动态、离屏、隐藏和页面离开统一停止或清理。
